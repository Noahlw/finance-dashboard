# CEO Plan: Google Apps Script Web App Architecture
Generated by /plan-ceo-review on 2026-07-16
Branch: main | Mode: SCOPE EXPANSION

## Vision

### 10x Check
By leveraging Google Apps Script's `HtmlService`, the entire system (Frontend, Backend, Database) lives natively inside Google Workspace. This completely eliminates the need for Vercel, Supabase, or external queues, while still providing a modern React-based UI for students and easily supporting a 10-year historical data scale (10 million cells).

### Platonic Ideal
The committee uses Google Sheets directly for ultimate flexibility and non-developer maintainability. Students visit a Google Apps Script Web App URL to submit claims. The Web App serves a bundled React frontend that communicates natively with the `SpreadsheetApp` service, bypassing any external API rate limits or authentication headaches.

## Scope Decisions

| # | Proposal | Effort | Decision | Reasoning |
|---|----------|--------|----------|-----------|
| 1 | Hybrid: Next.js + Sheets API | L | REJECTED | Requires external hosting (Vercel) and dealing with Sheets API rate limits (60/min). |
| 2 | Pure Apps Script Web App | M | ACCEPTED | 100% self-contained in Google, no API limits, supports custom UI via HtmlService. |

## Accepted Scope (added to this plan)

- Build a React SPA that compiles to a single `index.html` file for `HtmlService`.
- Backend functions exposed via `google.script.run` for seamless RPC.
