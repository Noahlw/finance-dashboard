## Governance

This domain covers wayfinder process, go-live approval, and schema migration policy.

### Key decisions

- Wayfinder maps close on decisions, not deliverables (ADR 0175)
- Schema migration canonicalizes by numeric column index (ADR 0176)
- Schema migration rollback recomputes derived state (ADR 0177)
- Go-live is owner-gated with checklist evidence (ADR 0179)
- Legacy event ID values never backfilled (ADR 0180)
