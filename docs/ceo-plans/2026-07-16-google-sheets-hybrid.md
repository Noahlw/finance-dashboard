# CEO Plan: Google Sheets + Next.js Hybrid Architecture
Generated by /plan-ceo-review on 2026-07-16
Branch: main | Mode: SCOPE EXPANSION
Repo: Budget

## Vision

### 10x Check
Instead of being artificially constrained by Airtable's 1,000 record limits and 100 automation run limits, the system will be built on a "Forever Free" stack capable of lasting 10+ years. It will comfortably handle expansion into high-volume features like Attendance Tracking, while providing a beautiful, custom web UI for students.

### Platonic Ideal
The system features a Next.js frontend (hosted on Vercel) for all member interactions (submitting claims, ticking attendance). The complex business logic (fraud prevention, budget rollups) runs server-side in Next.js. The data is stored in Google Sheets via the Google Sheets API. If the Next.js app ever degrades, the 5-person committee can simply open the Google Sheet and manage the club's finances manually, providing the ultimate non-developer safety net.

## Scope Decisions

| # | Proposal | Effort | Decision | Reasoning |
|---|----------|--------|----------|-----------|
| 1 | Abandon Airtable | S | ACCEPTED | 1,000 record limit is fatal for 10-year longevity and attendance tracking. |
| 2 | Pure Next.js + Postgres | L | SKIPPED | High maintenance risk if the club loses developer talent in the future. |
| 3 | Hybrid: Next.js + Google Sheets | L | ACCEPTED | Provides unlimited data scale, custom UI, and a native spreadsheet fallback for non-developers. |

## Accepted Scope (added to this plan)
- Custom Next.js web application for member frontend.
- Vercel for free hosting and serverless function execution (bypassing automation limits).
- Google Sheets as the primary database, accessed via Google Service Account (Sheets API).
- Future expansion: Attendance tracking (deferred to follow-up phase).
