## Budget

This domain covers budget requests, budget lines, and funding.

### Key decisions

- Budget requests can have multiple lines, each independently decided
- Budget availability is advisory at claim intake (over-budget lines remain selectable with warnings)
- Treasurer resolves over-budget claims
- Lines retain requested and approved amounts separately
- Approved lines need Treasurer correction path
- Closed budget requests cannot reopen for claims
- Only approved requests fund claims
