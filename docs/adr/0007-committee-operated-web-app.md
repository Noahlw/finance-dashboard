# Web app is operated by committee members

Status: accepted

The React/Vite web app served by Google Apps Script HTML Service will be used only by authenticated committee users. Members submit claim details and receipt photos through the committee's WhatsApp process; a Committee Operator downloads the photo, records the Claim, and attaches the receipt in the web app. This keeps the first release aligned with the real operating process and avoids requiring members to create accounts, while making committee identity and auditability essential requirements.
